# A01 OFD 票据完整渲染与抽取入口

基线：`ac1a6a5343e79b7027dce1a89fa73401939d9d41`。按用户连续开发和推荐方案授权实施。本计划补齐现有 OFD 管线；已验证的基础图元、模板、字体、静态批注和复合图元不另建实现。

## 调用链与职责

- 调用方：票夹抽取页面 → `InvoiceExtractionController` / `InvoiceExtractionService.prepare` → `InvoiceExtractionSources`。
- 下游：`InvoiceOfdInspector` → `InvoiceDocumentProcess` → worker → Archive / Document / Renderer → 全部 PNG；`InvoiceExtractionEngine` 重读并核对冻结来源后交现有模型适配器。
- 渲染兼容、签章外观、字体和资源限制属于隔离渲染基础设施；可信字体配置来自部署环境；权限、原件摘要、任务幂等、人工复核及正式财务查验继续由现有应用/领域层承担。
- 受影响场景：真实 OFD 票据的全页候选抽取、缺字/缺章/超限时整份失败、多页证据定位、身份与源变化、重试及重启后恢复。

## 明确边界

完整意味着每个文档、每页和所有可见内容均经过解析与绘制，不允许跳过未知图元、后页、后章或失败页面。遇到不支持内容整份失败，不能给模型部分来源。签章图像呈现不声明密码学验签、证书有效性或发票真实性；不访问签名中的外部链接。抽取结果仅是待本人确认的候选。

沿用独立进程、原件大小、解压、XML、字体、像素、时间与输出上限；嵌套印章与正文共享累计限制。字体必须从受信配置精确匹配名称、样式、face 和 SHA256；缺少字体失败，不能静默使用系统后备字体。诊断字体替代不得算作忠实票面验收。

公开原样本与来源摘要保存在 `/fyoung/tmp/agentflow-remaining-20260928/a01-research-20261007/public-sources.json`。标准原件和固定 OFDRW 2.4.0 源码用于核对结构；不修改样本后冒充原件通过。
