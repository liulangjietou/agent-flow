# W02 高级设计器交互补齐

V03 对照原始 `01-UI设计说明.md` §4 的 61–95 行，实际入口为 `App.vue` 的高级画布、节点面板、属性连线及应用级键盘监听。下游是唯一的 `nodes/edges` 草稿、撤销快照、自动保存、既有预检和发布服务。影响插入、删除、分支先后、鼠标/触屏连线与键盘移动；不改已发布定义、运行实例或服务端语义。

现有测试为什么遗漏：布局与序列化有覆盖，实际画布事件未被运行；快速步骤的图编辑验证不能证明高级画布也具备相同行为。

职责：图编辑规则属于前端草稿编辑层，拖线和属性连线共享同一实现；指针捕获/键盘焦点和单次撤销由页面处理。既有服务端仍负责发布不变量，不新增旁路接口。

- [x] 用实际 App 函数和实际画布模板复现误删除、缺少接续、方向键/Ctrl+Y、端口拖线及分支顺序问题。
- [x] 修复连接/插入/删除规则与默认分支顺序；保留条件、扩展属性、旧标识和未触及图分支。
- [x] 鼠标/触屏端口使用 Pointer Events，支持取消、变更身份/草稿及锁定时收尾，成功一次操作一份撤销。
- [x] 画布焦点内 Delete/方向键，输入框和工具栏不受影响；连续方向键合并至松键，50 份历史和 Ctrl+Y。
- [x] 相关前端回归、类型检查、构建、OpenAPI；证据归档并合入本地 main。

真实浏览器保持既有门禁，不重试或替代为其他浏览器；组件运行和样式检查只标记其自身证据。V03 继续核对其他原始条款。

结果：14 项交互与相关范围共 86 项通过，类型检查、构建、OpenAPI 通过。见 [证据](../../evidence/designer-interactions-20261007.json)。真实浏览器仍待补验。
