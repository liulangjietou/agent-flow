依据 UI 规范 01:119、144，每个实际减少含税额或可抵扣税额的费用行分别选择原因。可以统一填写后逐行调整；未修改金额的行无需选择原因，也不进入请求。提交说明仍必填，混合原因在整次核减中归类为 OTHER，各行实际原因完整保留。核减历史逐行展示原因，旧记录显示当时的统一原因。

请求新增可选 reasonCode，省略或传空时沿用统一原因；非法类别和隐式数字枚举均拒绝。旧记录缺少逐行字段时不补写字段，因此不会因读取或升级改写既有 JSON 及其摘要。接口和 OpenAPI 同步扩展，没有新增迁移或调整历史金额。
