# 收单材料核对与缺件退回

2026-10-07，U04 已完成本地实现和自动验证，浏览器、触屏及辅助设备验收待补。依据 UI 规范 01:123、142–143、147；[机器证据](evidence/expense-receipt-checklist-20261007.json)包含原失败、源码摘要和最终构建。

打开收单确认时，本轮报销单及已关联发票的纸质材料均未勾选。办理人逐项核对后才能签收；存在缺失时，按钮和处理器都阻止签收。“缺失并退回”将缺失项预填到现有退回表单，办理人可以修改并明确确认，点击缺件入口本身没有写入请求。

预填使用稳定费用行号和材料序号，不自动带入发票标识、账户、金额或费用描述。勾选仅是当前页面的人工核对，不能替代电子发票原文件；原签收记录和审批审计继续由既有业务链保存。

费用表单生成原上下文的草稿，详情向父待办传递，App 在等待视图更新前后复核身份、申请、任务和版本。TaskActions 再核对当前任务与退回权限，并保留代理选择和非空原因校验。已有人工意见、加签表单、旧账号或旧版本不能被预填覆盖。取消或换版本后必须重新核对材料。
