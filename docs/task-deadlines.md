## 已实现的配置边界

人工审批节点可选填三项字符串属性：

| 属性 | 含义与边界 |
| --- | --- |
| deadlineCalendarId | 同租户工作日历的完整 UUID |
| deadlineCalendarRevision | 明确历史修订号，正整数，不支持 latest 或表达式 |
| deadlineWorkingMinutes | 1 至 527040 个工作分钟 |

三项必须同时存在且有效；非人工节点不允许设置。未配置期限的旧节点保持原属性。设计器加载、保存、撤销和重做保留明确修订，不因目录刷新或日历新增修订而自动更新引用。已有非法配置保留原文并交由校验报告，不会静默当成无期限。

`TaskDeadlinePolicy` 值对象负责属性的语义与完整性；`DefinitionValidator` 负责节点适用范围。流程应用服务在发布前读取同租户日历的精确修订，缺失时返回 `DEADLINE_CALENDAR_UNAVAILABLE:<节点>`，不会发布引擎定义。日历仓储属于领域端口，应用层负责跨上下文读取。

设计器调用以下只读接口，允许 ADMIN 或 PROCESS_ADMIN；日历管理接口仍只允许 ADMIN。响应禁止缓存，不返回完整企业作息规则。分页默认 30 条、最多 100 条。

- GET `/api/v1/process-definitions/calendar-options`
- GET `/api/v1/process-definitions/calendar-options/{id}/versions`
- GET `/api/v1/process-definitions/calendar-options/{id}/versions/{revision}`
