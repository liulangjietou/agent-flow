# Agent 摘要运行记录

申请详情和待办详情的「Agent 摘要」可以分页查看已有运行，展开模型原文、来源标识与内容指纹、人工修订和运行元数据。没有运行时显示明确空态，不插入演示摘要。后续已接入受控模型生成、重新生成和人工复核写入口，当前调用链及授权以[Agent 执行与人工复核](agent-execution.md)为准；本文保留运行查询阶段的设计和验收记录。

## 调用链与 DDD 职责

`AssistRunRecords` → `AssistRunController` → `ApprovalApplicationFacade.get` → `AssistRunQueryService`。Controller 复核申请的实时可见权限，查询服务编排已经授权的申请和运行记录；目录经 `AssistRunReadPort` / `JdbcAssistRunReadAdapter` 做有界投影，详情经 `AssistRunRepository` 恢复原聚合并验证申请绑定。

申请人、同租户 ADMIN 和当前按现有规则可见申请的流程参与者可以读取运行目录。运行详情还须通过[字段权限](organization-context-and-field-permissions.md)检查：模型原文与人工修订是自由文本，不能可靠按字段删减；看不到该轮完整表单输入的身份读取完整运行详情返回 `403 FORBIDDEN`，管理员同样受限。运行发起人身份本身不授予申请访问权；失去参与关系后，原游标和原运行 ID 不能继续读取。PROCESS_ADMIN 不额外获得申请读取权限。查询不会调用模型、修改申请、操作 Flowable 任务或追加人工复核。

`AssistRun` 继续负责自身状态、证据匹配和复核不变量。查询页不另建运行状态，也不把可见性当作人工复核或审批操作权限。后续已确认的规则要求当前有效审批人显式复核，采纳摘要不会批准申请。

## HTTP 契约

| 方法与路径 | 行为 |
| --- | --- |
| `GET /api/v1/applications/{id}/assist-runs` | 运行目录；可选 `roundNo`、`limit`、`cursor` |
| `GET /api/v1/applications/{id}/assist-runs/{runId}` | 单运行详情；拒绝查询参数 |

目录默认 20 条、最大 100 条，按数据库创建时间及 ID 倒序，返回 `items` 和显式 `nextCursor: null`。列表不含模型正文、人员信息和输入清单；只有打开详情才加载这些内容。游标绑定租户、用户、角色、申请和轮次筛选，每次翻页仍重新授权；它不是访问凭证或冻结快照。时间使用数据库存储精度，避免 JSON 纳秒精度与数据库微秒精度不同造成重项。

未知、多值、非法或越界查询返回 `400 INVALID_AGENT_QUERY`；匿名 `401`；申请或运行不存在、不可见、跨租户或归属不符 `404`；已通过申请授权但字段权限不足以读取完整运行详情时返回 `403 FORBIDDEN`。成功响应均为 `Cache-Control: no-store`。本功能最初验收时累计 62 个操作、110 个 schema、21 个请求样例；当前契约统计见最新交付记录。

详情将原始模型建议与 `review` 分开返回，包含输入申请版本和查询时申请版本。`inputCurrent=false` 只说明源上下文已经变化，不改变原记录，更不授权采纳或审批。执行失败只返回稳定失败码，不返回远端错误正文或密钥。状态和时间为空时显式返回 null；复核中可选的修订文本、说明沿用全局非空序列化规则。

## UI 行为与边界

- 申请详情与待办共用同一组件，支持轮次筛选、继续加载、详情重试和刷新。
- 模型原文、人工修订、说明、源标识全部按纯文本展示，不执行 HTML、Markdown 工具或外部链接。置信度明确标为模型自报值。
- 旧输入显示历史警示；失败运行显示失败分类，等待执行的运行不伪造结果。
- 切换账号、申请、申请版本或关闭组件会同时中断目录/详情请求、清空已读内容；迟到响应不能恢复旧正文。任何查询遇到 401/403/404，目录和详情一起清除。
- 来源引用只显示标识和内容指纹，没有原始证据正文，也没有证明陈述真实。执行、字段选择与复核写入的后续实现及证据见[执行阶段](agent-execution.md)，查询记录本身不触发这些动作。

V20 只为 V19 的运行表新增申请/轮次目录索引，不补造旧摘要或修改原运行。双库迁移与原业务保留均需独立验证。
