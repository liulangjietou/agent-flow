设计器的快速步骤和高级画布共用节点期限配置；保存、复制和发布经定义应用服务、领域聚合、JDBC 仓储，再由 Flowable 适配器部署。版本治理只修改原版本发起开关及修订，通知配置、图和表单仍来自该记录。此处的数据恢复属于仓储和聚合，不能在页面加载时拼接默认文案。

本轮合入已发布的通知文案与并行设计器，补齐共同恢复通知配置和发起开关的仓储映射。组合集成测试覆盖日历已到 V2 时，原并行流程仍固定 V1、480 分钟；停用、复制、发布、恢复不丢失通知文案。副本期限 960 分钟及新通知文案不会改写原版本。

旧分支和新主线都包含 V24，迁移测试先稳定失败。本轮仅将未发布的治理迁移改为 `V25__definition_availability.sql`，已发布的 21 个迁移文件逐字节保持；原开发树补丁和 23 个未跟踪文件摘要保持一致。

模板文件调用链为文件解析/导出 → 节点属性白名单 → 服务端预检 → 独立草稿 → 重新校验后发布。原测试只覆盖无期限模板，未覆盖新节点属性；新增组合用例先复现导出拒绝，再补入三项期限属性。目标租户缺失日历时，允许导入待配置草稿；引用不自动切换或伪造，格式错误仍拒绝，发布仍必须解析当前租户的明确修订。页面提示同步包含期限日历和通知文案。
