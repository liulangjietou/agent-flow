# 流程版本比较

在“流程管理”打开“版本比较”，选择同一流程标识的已发布版本作为基线，然后点击“比较当前内容”。当前画布和表单的未保存修改也会参与比较。首次发布前没有基线，界面会明确提示；发布版本之间也可以比较。

比较只读，不保存草稿、不发布或回滚版本，不改变已有申请。修改设计、切换基线或账号、关闭面板后旧结果立即清除；请求取消与迟到响应隔离保证旧差异不会回填。

## 比较范围

| 类别 | 显示内容 |
|---|---|
| 流程信息 | 名称变化 |
| 节点与审批人 | 节点增删、名称、类型和全部非布局属性，包括当前审批人规则 |
| 连线与条件 | 连线增删、起终点、条件和默认分支标志 |
| 分支优先顺序 | 同一排他网关的非默认分支先后顺序，影响首匹配结果 |
| 表单结构 | 是否绑定表单、表单格式版本、字段填写顺序 |
| 字段配置 | 字段增删、名称、类型、必填、帮助、文本长度、精确数值边界和可选项 |
| 画布布局 | 节点 x/y，单独分组并默认收起 |

对象按节点 ID、连线 ID 和字段 key 匹配。字段 key 改名表现为删除旧字段、新增新字段，不自动猜测迁移关系。不同网关之间的全局连线重排不算优先级变化，默认分支的位置也不影响首匹配顺序。字符串条件按保存配置比较，不做逻辑等价化。

“定位当前配置”可定位仍存在的节点、连线或字段；已经删除的对象保留原配置供核对。旧图没有坐标时，编辑器自动补出的展示位置不会被写入快照或报告为布局变化，实际移动后才保存对应坐标；编辑器不认识的原节点属性也完整保留。差异清单不替代服务端发布校验，也不证明外部审批人存在或组织授权正确；尚未接入的审批矩阵、节点字段权限没有被当作已实现能力。

## API 与 DDD 职责

`POST /api/v1/process-definitions/{baselineId}/compare` 要求 `ADMIN` 或 `PROCESS_ADMIN`。请求包含必填 `key`、`name`、`graph` 以及可空的 `formSchema`。这是完整的当前快照，`formSchema: null` 表示未绑定表单；与更新草稿接口中 null 保留旧表单的兼容语义不同。

应用服务通过租户仓储读取基线，要求其已发布且 key 相同，再调用领域 `DefinitionDiffService`。纯领域比较不依赖 Spring、数据库或 Flowable；无需当前图已经满足发布条件，以便管理员比较编辑中的节点和连线。

响应包含服务端读取的 `baseline`（id、key、name、version）和 `changes`。每项差异包含 `area`、`kind`、`targetId`、`label`、`property` 与可选的 `before` / `after`；缺少一侧值表示该侧没有配置。`kind` 为 `ADDED`、`REMOVED` 或 `MODIFIED`。前后值保留原始十进制字符串，前端转为普通文本并由 Vue 转义渲染。

匿名返回 401，普通审批人返回 403，其他租户或不存在的基线返回 404。未发布基线返回 422 / `COMPARISON_BASELINE_REQUIRED`，不同 key 返回 `COMPARISON_KEY_MISMATCH`，重复节点或连线标识返回 `COMPARISON_ID_AMBIGUOUS`，避免覆盖重复对象后报告虚假的“无差异”。

接口无需 `Idempotency-Key`，不产生写请求恢复记录，也不增加数据库迁移。

## 验证

```bash
python3 scripts/check-definition-comparison.py http://127.0.0.1:8080
```

脚本要求演示租户已存在带人工节点的已发布流程；它比较已有发布版本与自身、未保存的新名称和审批人规则，验证权限、不同 key 和重复连线拒绝，并核对定义、申请、任务、模板列表前后相等。脚本不创建或删除业务数据。

领域测试覆盖分支顺序、节点增删、审批规则、布局、字段顺序、选项、精度、无表单与空表单，以及重复身份。集成测试覆盖实际基线、跨租户、角色、请求字段和完整业务/引擎运行表快照不变。前端测试覆盖基线筛选、不可变请求快照、取消与迟到响应、错误隔离、格式化和只读 API 行为。
