# 管理员审计摘要导出

ADMIN 在“操作审计”查询后点击“生成 Excel”，成功后可下载 `agentflow-audit.xlsx`。导出已查询条件的全部匹配事件，不受列表已加载数量影响；最多 10,000 条，超限整次拒绝，要求缩小筛选，不返回截断文件。

修改筛选、重新查询、切换账号或离开页面会清除旧文件及下载链接。生成期间可取消等待，60 秒未完成会超时；这些动作不保证服务端已经停止计算，但迟到响应不会恢复旧文件。空结果仍生成带表头和说明的有效工作簿。生成结果仅在服务端和浏览器内存中暂存，下载后保存的文件由操作者管理。

## 文件与业务口径

“操作审计”工作表包括记录标识、事件标识、事件来源、来源对象、聚合版本、动作代码、操作人账号、操作时间（UTC）、关联申请标识、业务单号、申请当前标题，共 11 列。按操作时间倒序，同时间按记录标识倒序；表头冻结并支持筛选。

“导出说明”包含租户、导出账号、生成开始时间、记录数、所有筛选及范围说明。日期包含页面指定的首尾两天，文件记录的时间终点是次日零点、不包含。结果来自一次数据库查询，之后可能出现新操作，关联标题是查询时的当前值。

任务 `APPROVE` 仅表示一次同意操作，不等于整单批准。旧事件缺失的操作人、动作或申请关联留空；无法关联申请的事件仍保留，不推断历史信息。不导出表单正文、审批意见或完整审计 JSON，也不是有签章的审计档案。

所有单元格均为 Excel 文本，不生成公式、超链接、宏和外部引用。长标识、超过 Excel 精确整数范围的版本号、前导零、中文、换行和 OOXML 字面转义保留原值。申请与审计工作簿共用 `TextWorkbook` 的文本编码和格式处理，各自保留业务列与说明。

## API 与 DDD 职责

`GET /api/v1/operations/audit/export`，仅当前租户 `ADMIN`。支持 `q`、`actor`、`action`、`source`、`applicationId`、`from`、`to`，与[审计检索](audit-search.md)同义；拒绝 `cursor`、`limit`、租户覆盖和其他未知参数。

| 响应 | 含义 |
|---|---|
| 200 | XLSX 二进制，文件完整生成后提交响应 |
| 400 | `INVALID_AUDIT_QUERY`，非法筛选或不支持的参数 |
| 401 / 403 | 未登录 / 非 ADMIN，包括仅有 PROCESS_ADMIN 的账号 |
| 422 | `AUDIT_EXPORT_LIMIT_EXCEEDED`，超过 10,000 条 |
| 429 | `AUDIT_EXPORT_BUSY`，当前实例正在生成另一份审计工作簿 |
| 503 | `AUDIT_EXPORT_FAILED`，工作簿生成失败，可重试 |

成功响应含固定安全文件名、`Cache-Control: no-store`、`X-Content-Type-Options: nosniff` 和文件长度。业务错误使用 JSON 错误协议，不附下载头。只读 GET 不需要幂等键。

调用链为 `AuditSearch.vue → AuditExportController → AuditExportService → AuditSearchPort / AuditWorkbook → TextWorkbook`。Controller 负责当前主体授权与入口条件解析；应用服务编排容量准入和一次摘要读取；基础设施查询端口负责租户隔离与 SQL，工作簿类负责输出表示。没有审批状态变化，不需要修改领域聚合，领域模块没有引入 Excel 依赖。

一次读取最多 10,001 行以检测超限，不循环列表分页，不加载聚合正文，不在下载期间占用数据库事务。每个服务实例同时只生成一份审计工作簿；申请导出有独立的一份容量，两类可同时生成。该限制是资源保护，尚无生产容量结论。没有新增数据库迁移，当前 schema 仍为 V20。
