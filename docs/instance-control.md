# 实例暂停／恢复与审批时限接续

当前阶段：**后端接口、领域计算及数据库范围验证已实现，操作页面和完整运行验收仍在接续**。本项尚不计为整项完成，项目仍有四个未完成工作包。长期验收服务目前保留此前的定时等待版本，没有因本次接口开发自动升级。

## 规则和职责

同租户管理员对当前在审轮次明确填写原因，并提交当前申请版本。暂停／恢复不改变申请的在审结论，不产生人工审批意见，不释放财务占用。当前轮次、实际实例、定义来源及受控租户变量必须一致；其他轮次、已结束实例、缺少平台暂停依据的原生暂停均不提供恢复操作。

入口负责请求格式、原因、版本和角色校验；应用服务先锁申请，再协调原生实例、任务期限、审计、通知与 Webhook outbox。任何一步失败回滚全部变更。成功响应按原请求幂等回放，回放仍检查当前管理员身份。暂停和恢复各增加一次申请版本。

人工任务在暂停时保留原到期时刻，恢复时使用任务创建时绑定的日历修订，计算原到期之前剩余的真实工作时长。午休、周末、假日和夏令时均按原开放区间处理，保留小于一分钟的精度；多次暂停只接续当时余额。暂停前已到期的任务保留原到期事实及已发送的提醒，不重新获得办理时间。日历修订或原期限依据不可用时，恢复整体失败。

定时等待保留实际激活时生成的原到期时间，暂停期间不推进；恢复后，已经到期的等待可由原调度继续。此规则与人工审批的工作日历 SLA 分开。

暂停后任务不进入可办理待办与超时任务统计，也不能审批、转交、加减签或发送超时提醒。超时提醒与暂停操作统一采用申请优先的锁顺序，并在锁后重读任务状态和期限。申请仍计为在审；暂停前的节点读取权限继续有效，管理员也不能突破敏感字段约束。申请人需要管理员恢复后再按原业务规则撤回。

## 接口

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | `/api/v1/applications/{id}/rounds/{roundNo}/runtime` | 读取当前绑定实例的运行、暂停、结束或不可用状态及当前操作能力 |
| POST | 同一路径加 `/pause` | 明确暂停原轮次 |
| POST | 同一路径加 `/resume` | 明确恢复原轮次并接续人工任务剩余期限 |

写入正文只允许 `expectedVersion` 和 `reason`，要求原请求幂等键；禁止查询参数和客户端提供新到期时间。响应不返回引擎变量或表单原文。`pausedAt` 在没有暂停依据时可以省略，所有响应禁止缓存。

`INSTANCE_PAUSE`／`INSTANCE_RESUME` 保存具名审计和原因；`APPLICATION_PAUSED`／`APPLICATION_RESUMED` 通知原申请人和实际有效办理人员，接收人去重，入口指向申请。Webhook 仅投递精简事件，不复制原因或表单内容。相关状态与原到期依据保存在已有 Flowable 表中，本阶段没有新增数据库迁移，仍为 V86。

## 已验证与尚未验收

本阶段范围验证见[后端证据](evidence/instance-control-backend-20261001.json)。领域覆盖秒以下精度、跨工作区间、日历修订、多次暂停和已超时；接口覆盖角色、租户、原轮次、旧版本、并发与幂等、双向通知故障回滚、原定时器、暂停期间字段权限、并行会签与无期限任务。提醒并发测试在暂停事务未提交时读取旧快照并等待同一申请锁，确认锁后不投递。

原测试只覆盖可办理或已结束的节点，未覆盖暂停状态。新增失败用例复现了暂停后字段读取权限丢失，修正参与节点查询后通过；另用实际序列化响应复现契约误要求空 `pausedAt` 的问题，契约改为可省略，与全局空值省略配置一致。

操作面板、未知结果的前端原请求恢复、实际 HTTP 契约、浏览器、窄屏、重启及既有运行库接续仍需补齐。自动化数据库验证不代表这些验收已完成，也不代表真实企业接入或远程 CI 已通过。
