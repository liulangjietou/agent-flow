# 原放款复核与银行退回

更新：2026-09-29。V59 为已经实际放款的员工借款增加独立银行退回复核。银行已退回公司的原放款单独减少借款欠款；员工主动还款及其后续退款保留各自记录。

## 规则与调用链

调用方为借款详情中的 `AdvanceDisbursementReturn` 面板，经受控 API 持久化查询意图；后台通过原付款固定目标的 `advance-disbursement-return` 只读端口取得证据。请求固定首次成功放款的完整命令和回单，不从当前账户目录重新拼接。

- `CONFIRMED`：原款仍成功到账，没有银行退回，财务确认后只解除原放款冻结。
- `PARTIALLY_RETURNED`：原款保持成功状态，至少一笔独立银行回款，累计严格小于原放款。
- `RETURNED`：原交易已撤销，全部独立银行回款恰好等于原放款；借款使用单独的“原放款已全额退回”状态。
- 原付款存在争议时，先完成原交易裁决。新入口不能绕过付款对账或替换原付款身份。
- 每笔银行回款必须有同额、同币种的员工借款贷方分录，最多 100 笔。资金发生时间不得早于原放款；两种原件必须完整，且在五分钟证据期内明确采纳。
- 新累计证据保留全部此前已见原件；不能遗漏、改金额或改分录。确认仅追加尚未确认的回款，原条目的决定编号不变。
- 已有报销冲销、净员工还款、银行退回及报销预留之和不得超过原放款。冲突时先核清相关占用，不能凭本次退回覆盖旧事实或产生负余额。

`AdvanceDisbursementReturnPort.Receipt` 负责外部证据的完整性，`EmployeeAdvance` 负责状态与金额守恒，应用服务负责任职、原轮次字段权限、并发锁及审计，仓储负责原件关联和防重约束。查询只可能冻结变化来源，不自行减少债务；独立财务确认才更新余额。原申请人和原执行出纳不能确认，管理员没有敏感字段或财务权限旁路。

金额关系为：未还款 = 原放款 − 已报销冲销 − 净员工还款 − 原放款已退回。实际放款本金不变，可用金额另扣当前预留；原放款冻结和每笔员工还款冻结分别保留。

## 持久化与接口

V59 新增查询、查询修订、独立决定及 `advance_receipt_credit`。共用账本回填全部原还款，以租户、法人、渠道、资金流水防重，同时对法人内贷方凭证和分录防重。银行退回与员工还款无论谁先确认，都不能再次使用同一入款或会计分录。

余额变化、查询单次消费、决定、全部新增入款及审计在一个事务内提交。第二条新增证据触发重复约束时，第一条也回滚，旧查询仍可读取。数据库不重写旧还款和旧借款修订；没有新字段的历史借款原文按零银行退回读取。

| 接口 | 行为 |
| --- | --- |
| `GET /api/v1/advance-requests/{id}/disbursement-review` | 原申请人读取原放款及已确认回款，当前独立财务另见自己的候选；响应禁止缓存 |
| `POST /api/v1/advance-requests/{id}/disbursement-review-checks` | 只提交当前借款版本和核对说明；202 表示查询意图已保存 |
| `POST /api/v1/advance-requests/{id}/disbursement-resolutions` | 提交展示的查询/借款版本、结论和核验材料；金额及原件只能来自已保存证据 |

写入复用原幂等请求恢复机制，每次重放前重新核验当前权限。后台领取后释放事务，90 秒租约超时有明确状态；传输失败不自动采纳或无限重试。可以通过 `agentflow.advances.disbursement-return-worker-enabled` 停用处理而保留查询意图。

## 本地验证

重点领域测试 8 项、H2 服务端 37 项、PostgreSQL 服务端 102 项、前端 27 项及构建通过；PostgreSQL 同轮还运行 15 项领域测试，其中包含上述重点范围，计数不相加。覆盖跨入口重复收款、先插入条目回滚、累计证据保留、原付款争议、占用冲突、当前任职及幂等回放失权、客户端身份切换和未知响应恢复。新增 PostgreSQL 还款集成及 V59 升级用例已纳入 CI 配置，远程 CI 尚未运行。

OpenAPI 为 174 个操作、320 个 schema、61 个请求示例。实际 HTTP 首轮 25 次、浏览器后 12 次（均含登录），31 份业务响应通过契约验证。实际浏览器先保留 HTTP 确认的 40 元，再明确确认新增 30 元；累计银行退回为 70 元。原 300 元放款、原员工累计收款 300 元及退回 170 元保持，净还款 130 元、未还款及可用余额 100 元。再次查询相同银行依据不增加回款、不重新冻结。

实际 500 CSS 像素宽度下，页面、对话框、余额及退回面板均无横向溢出，临时视口已恢复。截图位于 `/fyoung/tmp/agentflow-remaining-20260928/disbursement-return-browser-saved.png` 和相邻 `disbursement-return-browser-narrow.png`。

现有本地验收库 V58→V59 升级保持 13 张表和 4 个附件原文，回填 2 条原还款入款记录。业务验收新增 2 个决定、2 条银行入款及 3 个查询；旧决定、原还款、旧借款修订、付款/凭证和原命令保持。升级前数据库备份为 548923 字节，文件配套保留。Java 作者检查为 735 个文件、1335 个命名类型，无缺失或解析错误。
