# 提交轮次内容对比

审批人可在待办的“内容对比”中核对补正前后内容；申请详情提供同一入口。默认选择最近两次真实提交，也可选择任意较早、较新轮次。没有快照或只有一轮时显示空态，不用当前草稿补造历史。

## 对比口径

- 比较每轮提交时保存的标题、流程版本和完整字段值。默认只看变化，可切换查看全部字段。
- 显示原值，不执行金额运算或规范化：`1.00` 与 `1`、字符串与数字都保留区别。大金额及小数位不会经 JavaScript 浮点数转换。
- 缺失字段、null、空文本、false、零分别显示；对象仅键顺序变化不计为修改，数组顺序变化计为修改。
- 字段名称、类型及选项从各自轮次的表单快照读取。配置变化单独标记，必要时展开两轮配置原文；后续发布的表单不会替换旧轮次解释。
- 同时显示轮次、版本、提交人、提交时间和退回/撤回原因。内容变化数包括标题和版本，不表示审批意见或状态发生了多少次变化。
- 未提交修改不参与对比。对比只读，仍需通过已有审批动作作出决定。

## 职责与权限

`App.vue` 待办 / `ApplicationRecord` → `RoundComparison` → 原 `GET /api/v1/applications/{id}/rounds` → `ApprovalApplicationFacade.rounds` 先校验申请读取权限 → `JdbcSubmissionRoundRepository.findAll(tenant, id)`。

`roundComparison.ts` 负责纯展示比较、真实轮次选择及请求生命周期；领域和服务端不新增状态或规则。标题、payload、formSchema 来自不可变提交内容，状态和处理意见仍按原审批链路更新。流程运行仍由 Flowable 负责。

切换账号或申请、卸载组件、刷新时清除旧数据并取消旧请求，迟到响应不回填。读取失败显示明确错误并支持重试；无权限不显示缓存内容。所有字段和配置原文通过 Vue 文本插值渲染，不解释 HTML，不在浏览器持久化申请快照。本阶段没有 Java、API 契约、数据库迁移或授权范围变更。
