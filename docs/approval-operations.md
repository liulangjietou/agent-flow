# 审批运营统计

管理员侧栏“审批运营”读取当前租户的提交轮次和真实待办。接口为 `GET /api/v1/operations/approvals`，仅允许 `ADMIN`，响应 `Cache-Control: no-store`；仅有 `PROCESS_ADMIN` 不获得全租户申请权限。

## 统计口径

- `from` / `to` 按 UTC 提交日期、包含首尾筛选，结束日期不得晚于 UTC 今天；默认结束日期为今天，开始日期为结束日期减 29 天；最大 366 天。
- 可选 `processKey` 精确流程标识；`definitionVersion` 必须与流程标识同时使用，为正整数。未知查询参数直接返回 `INVALID_OPERATIONS_QUERY`，不接受客户端提供租户或身份。
- 可选 `organization` 按各轮提交时冻结的法人、部门或岗位名称做忽略大小写的包含匹配，最多 128 字；`%`、`_`、`!` 均为字面量。该筛选可以命中多个同名组织，不代表精确组织 ID 或下属组织范围。响应回显已应用的组织条件。
- 退回率 = 退回轮次 ÷（批准 + 退回 + 驳回轮次）× 100，四舍五入到一位小数。撤回和审批中排除；分母为零时不返回比例字段，界面显示“—”。这是用户确认的业务规则。
- 同一申请重提另计一轮；提交日期决定统计队列，结论取查询时该轮次的状态，因此结论可能在日期窗口结束后才产生。
- 平均用时仅统计已批准且完成时间不早于提交时间的轮次，按秒四舍五入；包含周末、节假日及等待。没有有效样本时省略数值，合法零秒显示零。
- 每日趋势补齐没有提交的日期。流程汇总按流程标识和版本分组，最多展示 50 个版本；总计和每日趋势不受展示上限影响。
- 当前积压不受提交日期窗口限制，按当前在审轮次的组织、流程及版本筛选。会签按每位成员的独立待办计数。节点和最早待办各最多展示 20 项，并返回截断标识。
- 缺少快照的历史轮次单独披露，不能补造提交日期或根据当前申请状态推断旧结论。这一缺失量只受流程及版本筛选影响，不受日期或组织筛选限制，因为没有事实能够确定旧轮次的提交时间和组织。
- 未提交的申请草稿不计历史缺口；作废申请仅在准确绑定的唯一审计证明由草稿直接作废时排除，退回或撤回后的旧历史缺口保留。见[草稿误报修复](known-draft-round-count.md)。
- 当前待办的超时数按已记录期限与查询时刻比较；未记录期限的任务不补推 SLA。完整历史 SLA 违约率、外部通知失败及 Agent 采纳率尚未接入，不能将未接入指标显示为零。
- 组织目录改名、人员调动或选择新任职重提不会改写旧轮次的归属。未记录组织的轮次在设置组织条件后不匹配，未筛选组织时仍保留。

## 调用链与职责

`App.vue → ApprovalOperations.vue → api.approvalOperations → ApprovalOperationsController → ApprovalOperationsReadPort → JdbcApprovalOperationsReadAdapter`。

入口完成身份及参数校验。领域读端口声明轮次、结论、任务和报告口径，`Metrics` 计算已确认的比例；数据库适配器执行聚合和只读快照查询，使用可重复读事务。SQL 汇总后返回有限列表，不把全量审批正文加载到内存，也不复制 Flowable 运行状态。

当前待办与个人工作台复用 `FlowableActiveTaskSql` 的租户、申请、活跃状态和当前轮次绑定检查。该共用 SQL 位于流程基础设施层，避免两条查询对引擎变量隔离采用不同规则。日分组使用 UTC epoch 日，规避 H2 将带时区时间转 DATE 时重新套用连接时区的问题。

组织筛选复用 V29 迁移保存的轮次组织名称列，不新增迁移。待办列表与运营统计均调用 `RoundOrganizationSearchSql`，集中维护名称转义和三类组织的匹配条件；这属于已授权查询的数据库谓词，不承担身份授权或修改轮次。

大规模数据的查询计划、索引和压力基线尚未验收；现有结果不能作为生产容量结论。

## 验证

Java 测试覆盖多轮重提、结论口径、UTC 跨日与时区偏移、空窗口、无效耗时、旧历史缺失、版本截断、真实会签积压及租户/轮次绑定异常。前端测试覆盖筛选、超时、切换账号、迟到响应、失败重试和无样本显示。

在独立演示数据库执行（会保留随机业务记录）：

```sh
python3 scripts/check-approval-operations.py http://127.0.0.1:8082 --exercise
node agentflow-web/scripts/check-openapi.mjs http://127.0.0.1:8082 --exercise
```

运行验收通过真实 API 创建会签流程，执行退回、重提、批准、驳回和撤回，并验证 22 项待办只返回最早 20 项、历史空窗口仍保留当前积压。脚本不输出会话令牌。
