# 外部冲销核对与登记通知

F17 的外部冲销核对现已接通原查询异常和人工登记通知、受控摘要及消息页面。它沿用既有只读 ERP 查询和明确登记流程；独立冲销命令的准备、发送与安全结束另见[独立冲销通知](reversal-notifications.md)。

## 调用链与职责

调用方是原凭证的财务核对入口和 `VoucherReversalWorker`。`VoucherReversalService` 在原申请与凭证锁内保存核对状态，下游分别是核对仓储、不可变登记仓储与审计；实际 ERP 查询在事务外执行。

新增 `VoucherReversalCheckChanged` 描述持久变化。普通核对更新后发布事件；明确登记时，先保存已消费的核对，再保存独立登记，最后发布事件。这个顺序满足登记仓储对已消费查询的校验，也避免消息早于真实登记出现。任一步失败都会回滚核对、登记、站内消息和外发意向。

领域对象继续判断凭证证据及登记边界。通知服务只负责原参与关系、最小文案与去重，不修改原凭证、银行资金、预算或借款资源。

## 原事实和参与人

消息键为 `reversal-check:<原核对 UUID>:<事实>`。每次明确新查询使用新的核对编号，旧消息不跟随最新查询；同一原凭证后来由另一核对登记，也不会把那条登记挂到旧失败消息上。

| 事实 | 通知含义 |
| --- | --- |
| `UNAVAILABLE` | 查询失败或租约超时，本次没有形成可登记结论 |
| `SOURCE_CHANGED` | 原凭证依据或核对资格变化，本次查询停止 |
| `UNRESOLVED` | 查询成功但完整反向凭证仍未核清，不能据此登记或恢复业务 |
| `RECORDED` | 原核对已由财务明确消费，并保存独立登记记录 |

排队、处理中和完整查询候选不生成业务完成通知。完整回执仍须人工明确登记；“未核清”也不表示原凭证没有发生冲销。通知随新的持久状态变化生成，不回填旧消息。

接收关系固定为原申请人和原核对人。生成消息时检查可信目录人员有效性；财务参与人还须在原法人保持有效任职。外发领取和人工重试重新检查原消息、原核对、原申请轮次、参与关系及当前任职，并沿用渠道偏好、同意代次与收件绑定检查。

## 读取和页面

`GET /api/v1/notifications/{id}/reversal-check-target` 只处理当前用户自己的消息，拒绝查询参数，响应 `Cache-Control: no-store`。按原核对号校验首次接受的原凭证和固定目标，登记还必须精确引用这次核对、原回执和原核对人。读取再调用 `VoucherAccess.read`，执行原业务的当前字段权限；管理员不能绕过。

响应仅包含原编号、状态、稳定原因、原查询证据日期和凭证号，以及该核对实际消费的登记编号与时间。不返回分录、账户、理由材料、网关目标、证据续期或写入许可。

消息中心点击“查看原核对”才读取摘要。页面区分本次未核清、未登记与实际登记，并提示回到原申请核对其他查询及当前业务状态。重新读取、身份或消息切换立即清空旧事实；超时、失权与卸载使迟到响应失效。页面只提供读取和原轮次导航。

## 回执时间精度

原 ERP 回执允许纳秒，既有夹具却只使用微秒。两条合法纳秒回执均已形成 `CHECKED` 候选，明确登记时仍因数据库时间列丢失精度而触发记录不一致并回滚；最小失败用例和日志已保留。

修复归属登记仓储：不可变 JSON 和公开摘要保留原纳秒证据，SQL 索引时间明确截断到微秒。读取同时接受旧版本直接绑定 `Timestamp` 后的微秒舍入值，不修改原证据。H2 实测较低纳秒尾数舍去、较高尾数进位；回归覆盖两种情况、旧写入方式以及偏移两微秒仍拒绝的边界。这不是 PostgreSQL 的实际运行验收。

## 验证边界

[本地验证记录](evidence/reversal-check-notifications-20261003.json)保存固定提交、源码摘要与测试日志。154 项 Java 用例通过，包括 45 项报销冲销范围用例、40 项借款回归、30 项收件箱与投递回归、29 项领域用例、7 项接口契约及 3 项迁移用例。按实际测试身份统计，没有把重复报告计入总数。

125 项前端用例通过，执行真实 Vue 脚本、模板及原轮次导航。类型检查、页面构建、作者检查和差异检查通过；OpenAPI 校验 348 个操作、698 个 schema 和 125 份请求样例。范围覆盖通知与登记事务、原核对身份、旧查询与新登记隔离、租约与迟到结果、权限和任职、原业务资源保持、切换清空与迟到响应失效。

固定安装包、非空运行升级、重启恢复、真实浏览器与 PostgreSQL 新范围验收仍待完成。企业 ERP 和通知渠道使用各自外部验收任务；本地回环及 H2 测试不替代企业验证。F17 还需补齐结算及其他财务恢复来源并完成整体验收，全项目已知未完成数量保持 34。
