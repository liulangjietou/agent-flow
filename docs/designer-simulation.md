# 流程设计器模拟运行

流程管理员在“流程管理”中打开“模拟运行”，填写测试数据后可查看经过的节点、连线和条件分支依据。模拟使用当前画布与表单，尚未保存的修改也会生效；结果可定位到节点或连线，并在画布上高亮。

模拟只计算路径，不保存定义、创建申请、执行审批或发送通知。表单、画布或测试数据变化，切换定义、会话或关闭面板后，旧结果立即失效；迟到响应不得恢复旧路径。测试值不存入浏览器持久存储。

费用流程启用跨单规则后，须单独填写合成路由金额。接口的 `splitRoutingAmount` 使用明确币种的金额对象，与 `values.amount` 分开；币种须同时匹配规则和本单测试值，合成金额不得低于本单。只有已标记的业务条件网关使用合成值，其他网关及财务复核仍使用本单金额。模拟不会查询现有报销单、生成冻结依据或修改费用；未启用规则时不接受合成金额。当前画布和已保存版本两个模拟入口遵守同一规则。

## 接口合同

`POST /api/v1/process-definitions/simulate` 需要 `ADMIN` 或 `PROCESS_ADMIN`。请求包含 `graph`、可空的 `formSchema` 和必传的 `values` 对象。此 POST 是只读计算，不要求 `Idempotency-Key`，也不产生待恢复的业务写请求。

响应包含 `path`（节点 ID 顺序）、`edgeIds`（连线 ID 顺序）以及 `decisions`（经过的条件网关）。每个决策包含 `nodeId`、`selectedEdgeId`、`branches`；每个分支包含连线、目标节点、条件和计算结果：

| 结果 | 含义 |
|---|---|
| `MATCHED` | 首条条件命中，采用该分支 |
| `NOT_MATCHED` | 条件已计算，但未命中 |
| `SKIPPED` | 前序条件已命中，本条件没有执行 |
| `DEFAULT_SELECTED` | 条件均未命中，采用默认分支 |
| `DEFAULT_SKIPPED` | 已有条件命中，默认分支不启用 |

分支按流程图中的连线顺序求值，命中后停止，默认分支只作兜底。编译器和模拟器共享受限条件 AST，模拟不会执行 JUEL、脚本或 Java。此语义与 [Flowable 的顺序流及排他网关说明](https://www.flowable.com/open-source/docs/bpmn/ch07b-BPMN-Constructs) 一致。

结构错误返回 HTTP 422、`INVALID_DEFINITION`，并以 `details.definitionErrors` 提供错误码及节点或连线 ID。表单错误返回 422、`FORM_VALIDATION_FAILED` 和 `details.fieldErrors`；无匹配路径返回 422、`NO_BRANCH_MATCHED`。匿名返回 401，无管理权限返回 403。

已有 `POST /process-definitions/{id}/simulate` 保留原 `{path}` 响应合同与原定义可见权限。

## 领域约束与兼容性

`DefinitionValidator` 统一检查创建、更新、发布、模板载入与模拟。`DefinitionSimulator` 是领域服务，在内存里计算路径；应用服务编排调用，控制器负责权限与请求合同。新接口不查询仓储，不调用 Flowable 运行实例。

当前支持无环的顺序流程和排他条件分支。普通开始、人工节点最多一条出线；开始节点不能有入线，结束节点不能有出线。普通节点的多出线在 Flowable 中可能产生隐式并行，无法用单条路径如实模拟，因此在当前受限图模型下拒绝。

新增校验不会修改或删除旧定义，也不迁移运行中的流程。旧图若有循环或隐式并行，将无法通过后续校验、编辑保存、发布或模拟；应先在新草稿里修正结构。并行会签、循环和子流程不属于当前模拟能力。

有表单时，模拟与正式提交使用同一字段规则及精确数字转换。无表单的历史图可输入 JSON 对象；仅支持简单字段值，小数与大整数必须写为字符串，例如 `{"amount":"6000.50"}`，避免 JavaScript 数字精度损失。

模拟结果不证明审批人存在、组织授权有效、外部服务可用或财务规则合规；这些能力需由相应实际依赖验证。

## 验证

```bash
python3 scripts/check-designer-simulation.py http://127.0.0.1:8080
```

脚本以演示管理员身份执行当前目录全部模板的样例、未保存条件变更、精确边界、权限和错误定位，并比较定义、申请、任务、模板列表前后相等。它不写业务数据，不删除既有记录。数据库表与引擎运行表不变、与真实 Flowable 路径一致性由 `DefinitionPreviewIntegrationTest` 验证。

浏览器验收包括必填提示、未保存阈值、默认分支、高亮、节点与连线定位、结构错误定位、编辑后清除结果和窄屏布局。自动测试还覆盖取消请求、迟到成功与失败、错误响应以及旧 JSON 输入精度约束。
