# 费用逐行纠错与分摊反馈

2026-10-07，U02 已完成本地实现、组件交互与固定包验证，真实浏览器和辅助设备验收仍待完成。依据原 UI 规范 01:105–114、135–138；[机器证据](evidence/expense-feedback-20261007.json)保留源码摘要、失败复现、执行记录和验收边界。

原来费用制度在领域冻结校验中拒绝某一行后，预检把它转换为没有行号的整单结果；前端既没有“去处理”入口，也漏配了实际的缺说明错误码。现在领域异常保留原行号，预检沿用既有 `Finding` 契约返回位置，不复制或放宽制度规则。

申请人可以从当前保存版本的预检结果定位原费用行。禁止项聚焦“移除此行”，缺少说明聚焦原因框，其他行级问题定位该行。本人新发起的预检及其轮询结束后，只在焦点仍停留于原操作位置时定位第一条阻断问题；历史读取、用户已经转移焦点、旧版本、已删除行、锁定和切换账号均不误跳。定位只移动焦点，不删除、保存或提交。

分摊输入按整数分即时显示已分摊、还差或超出金额；大额的一分钱差异保持精确。币种不一致、非法金额和未完成输入不会被标为配平。保存仍由原有统一入口执行完整校验。
