流程管理中的画布支持缩小、放大、适应画布和自动布局。保留原有节点编辑、连线条件、撤销/重做、模拟高亮和版本比较。

## 操作与保存

- 缩放范围为 50%–160%，以当前可视区域中心为基准。缩放、适应和滚动都不进入定义快照，不产生未保存修改。
- 适应画布同时考虑节点、连线及条件标签。流程过大时停在 50%，保留滚动并提示继续查看；不会隐藏固定画布尺寸之外的节点。
- 自动布局沿流程方向分列，汇合节点位于所有前驱之后，同列分支分行排列。一次操作对应一次撤销，重复执行得到稳定位置。
- 自动布局只修改节点 x/y；仍需点击“保存草稿”。审批人规则、自定义属性、节点和连线标识、分支条件、默认分支及出线顺序均保留。
- 拖动在不同缩放下使用一致的逻辑坐标，并计入画布滚动。松开、取消指针、切换流程或离开设计器都会结束拖动；节点面板拖入的位置按落点换算。
- 已发布定义只读，可缩放、适应和查看；自动布局及节点修改受原有编辑锁和流程管理权限控制。

## 职责与数据链路

调用入口是 `App.vue` 的画布操作，几何计算放在 `designerLayout.ts`。视图状态留在前端；节点位置继续经 `designerGraph.ts` 合并到原 `properties`，使用已有保存接口和 revision 校验。领域定义、表单、受限条件、Flowable 部署和数据库结构均没有新增职责或改动。

自动布局按有向图的最长路径分层，保留原出线顺序。含回环或断开节点的未完成草稿也能整理展示，但回环仍保留并提示修复；布局成功不等于流程校验通过。重复节点标识直接报错，不替用户改标识。

连线路径由当前节点坐标确定，优先使用直达折线；存在障碍时选择可用的水平通道。无需持久化第二份连线数据，重载后仍使用同一算法。手工放置的节点相互遮挡、无法绕开时保留连线并提示调整，不宣称所有任意图均能消除交叉。长条件标签缩略显示，悬停可查看全文，保存内容不截断。

历史坐标含非法数字、无穷值或负数时，加载阶段使用有限非负的展示位置，避免画布整体失效。节点未移动时仍保留原属性；只有实际布局或拖动才提交新坐标，不静默改写历史数据。

## 验证

在 `agentflow-web` 执行 `npm run test:requests` 和 `npm run build`。布局回归覆盖不等长分支汇合、连线避障、回环、断连、重复标识、250 节点长链、几何边界、不同缩放的拖动、条件标签与语义保留。`designer-graph.test.mjs` 包含非法坐标的失败复现及修复回归。

浏览器验收步骤：

1. 在独立验收环境创建含不等长分支的草稿，放置一个超出原 1600 像素范围的节点。
2. 缩放和适应后确认坐标不变、草稿无新增修改；自动布局后撤销、重做，核对原位置和整理后的位置。
3. 与同一流程的已发布基线比较，确认变化仅在画布布局；保存并刷新，核对坐标、完整属性、边顺序及表单。
4. 分别在 50% 和 160% 下拖动相同比例的屏幕距离，确认相同逻辑位移、松开后不残留拖动状态。
5. 400 CSS 像素宽度下确认工具栏可用、页面不横向溢出，较宽流程可在画布内滚动。
6. 打开已发布版本，确认自动布局不可用，查看操作不改写发布快照。

本功能仍限定于当前支持的开始、结束、人工审批和独占网关；不是完整 BPMN 编辑器。高级节点、并行会签、任意连线路径编辑及移动触屏设备专项验收不包含在本次交付中。
