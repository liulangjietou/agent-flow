# 员工与审批者图文操作手册

本手册面向员工和审批者，按实际界面说明创建、保存、提交、审批、查询和异常恢复。正文共13章，配有29张项目界面截图；Word和PDF均为58页。截图取自2026-10-08的独立本地演示环境，账号、法人、单号和金额为示例。操作时仍需核对本人的权限、有效任职、单据状态和已发布流程配置。

## 内容范围

- 员工操作：普通表单审批、事前申请、费用报销、员工借款、采购付款、预算调整，以及保存、提交、撤回、退回补正、重新提交和作废。
- 审批办理：待办查询、领取与释放、批准、退回、驳回、转交、委派与回交、会签和有效代理身份。
- 配套功能：附件、个人票夹、批准额度、借款余额、提交轮次、内容比较、流程图、轨迹、审计、评论、通知、电子签和Agent辅助。
- 操作边界：按钮开放条件、金额和资源校验、预检有效期、职责分离、结果未知恢复及版本冲突处理。管理员、财务和出纳仅说明交接职责及结果，不展开其全部后台操作。

审批通过、预检完成、实际付款、资源核销、单据归档和预算调整生效分别核对，不能互相替代。

## 文件维护

`manual.md`为可审阅的正文，图片使用`assets/`中的相对路径。Word已嵌入全部截图；PDF由同一份Word导出。完整资料包中的Markdown图片目录同样为`assets/`，解压后应保留相对位置。

修改操作说明、按钮名称或截图时，同步更新在线正文、Word、PDF和完整资料包，并重新检查目录、图注、页码及图片路径。当前交付已完成正文事实核对、读者操作检查、58页视觉核验和压缩包完整性检查；后续版本应按当时的实际界面复核。
